# Fimathe Backtests

Painel estatico para consulta e comparacao dos backtests Fimathe. Os dados ja
processados para o navegador ficam em `painel/dados/`.

## Atualizacao local

1. Atualize a biblioteca local de backtests em `2026/`.
2. Execute `Atualizar-Painel.cmd` para reconstruir os dados do painel.
3. Revise as alteracoes, faca commit e envie para o repositorio.

Os relatorios brutos e as copias de seguranca em `2026/` permanecem locais e
nao sao enviados ao GitHub. O painel nao oferece recomendacao financeira nem
garantia de resultado.
